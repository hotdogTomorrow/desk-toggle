## 可重复检查

| 检查 | 方法 | 预期 |
| --- | --- | --- |
| 手势规则 | `ctest --test-dir build -C Release --output-on-failure` | 所有检查通过 |
| Shell 显隐 | `shell_probe.exe --roundtrip` | 切换成功，最后恢复初始状态 |
| 自启项 | `shell_probe.exe --startup-roundtrip` | 关闭、开启、带引号路径、关闭均成功，最后恢复原值 |
| 空闲占用 | `scripts/Measure-Idle.ps1` | 记录 CPU 时间增量、工作集、私有内存，注明交互阶段 |
| 隐私 | 检查 Git 暂存文件与 Release EXE 字符串 | 不含本机个人路径、凭据、日志和截图 |

探针不打印用户名、桌面项目名称或启动项中的本机路径。自启探针保存并恢复原有值，而不是假设原先一定没有启动项。

## 手工验收清单

- [ ] 真实鼠标：双击空白隐藏，再双击恢复；两次切换均有效。
- [ ] 图标：正常双击快捷方式、文件夹，图标显隐状态不改变。
- [ ] 框选：拖动到远处再回到起点松开，不触发；拖拽后紧接一次单击也不触发。
- [ ] 图标隐藏后，桌面右键菜单可正常打开。
- [ ] 多显示器：副屏与负坐标显示器均能切换；窗口、任务栏双击不触发。
- [ ] 100%、150%、200% 缩放：点击图标边缘和文字均不误判为空白。
- [ ] 托盘：菜单可键盘操作，勾选／取消自启正常，取消后本程序启动项被删除。
- [ ] 登录：打开自启后注销再登录，程序启动；关闭后再次登录不启动。
- [ ] 重复启动：只保留一个常驻实例。
- [ ] 正常退出：恢复本程序隐藏的图标；启动时就隐藏且未切换的桌面保持原样。
- [ ] Explorer 重启：托盘恢复，重新双击仍有效。
- [ ] 睡眠恢复／锁屏解锁：旧的未完成点击不与新点击组成双击。
- [ ] 持续移动鼠标：分别测量常见回报率和高回报率鼠标的 CPU。
- [ ] 动态壁纸／远程桌面：单独记录软件与环境；不以普通桌面结果代替。

不要在别人正在使用的桌面上自动注销、重启 Explorer 或改变显示器设置。正常退出可恢复图标；如果应用被强制终止或 Windows 正在结束会话，使用系统桌面菜单或 `DeskToggle.exe --show` 恢复。
