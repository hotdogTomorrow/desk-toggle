DeskToggle 首个公开版本：双击 Windows 11 桌面空白处隐藏图标，再双击恢复。

## 下载后直接运行

- **大多数 Intel／AMD 电脑**：下载 `DeskToggle-x64.exe`，放在固定文件夹中，双击运行。
- **Windows ARM 电脑**：下载 `DeskToggle-ARM64.exe`，双击运行。
- 想保留说明与许可证：下载相应架构的 ZIP，解压后双击里面的 `DeskToggle.exe`。

**不需要编译、不需要安装开发工具或额外运行库，也不需要管理员权限。**

GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码；普通用户请选择上面的 EXE 或 `DeskToggle-*.zip`。

运行后在任务栏通知区域找到蓝色显示器图标，右键菜单可设置开机自启、显示图标或退出。自启默认关闭；托盘图标可能位于折叠菜单中。

## 功能与验证

- 支持系统双击间隔与容差，排除图标点击、修饰键点击和拖拽。
- 正常退出时恢复本程序隐藏的图标。
- 原生 C++ / Win32，无联网、遥测、广告或自动更新。
- x64、ARM64 Release 均由 GitHub Actions 编译；x64 手势规则测试共 24 项通过。
- 附带每个 EXE、ZIP 的 SHA-256 校验文件。

## 已知情况

曾收到一次桌面图标偶发闪烁的反馈，目前尚未复现定位。ARM64 已通过编译，尚未在实际 ARM 设备上运行验收。

异常退出后如果图标仍隐藏，可在桌面右键 → 查看 → 显示桌面图标中恢复。
